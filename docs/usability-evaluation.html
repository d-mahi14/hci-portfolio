Part 3: System Usability Scale (SUS) Protocol

The 10 Standard Brooke (1996) Items

  1. I think that I would like to use this website frequently.
  2. I found the website unnecessarily complex. (Inverted polarity)
  3. I thought the website was easy to use.
  4. I think that I would need the support of a technical person to be able to use this website. (Inverted polarity)
  5. I found the various functions in this website were well integrated.
  6. I thought there was too much inconsistency in this website. (Inverted polarity)
  7. I would imagine that most people would learn to use this website very quickly.
  8. I found the website very cumbersome to use. (Inverted polarity)
  9. I felt very confident using the website.
  10. I needed to learn a lot of things before I could get going with this website. (Inverted polarity)

Scoring Formula

Standard Brooke Formula:
Odd items (1, 3, 5, 7, 9): Points = (Scale Value − 1)
Even items (2, 4, 6, 8, 10): Points = (5 − Scale Value)
Total SUS Score = (∑ Points) × 2.5   [Range: 0 to 100]
